# 部件补绘请求

使用内置 imagegen，未使用 API/CLI 生图。编辑基准始终是 v13。下列输出是内部补绘板，只取需要的隐藏区域，整张输出不直接替换运行时角色；校徽与求是鹰始终来自独立官方矢量。

1. **隐藏皮肤、衣料与头发**：保持画布、位置、头身比例、倾斜和墨蓝银蓝手绘笔触；移除双手、袖口和键鼠，补出原位置的完整小躯干与被遮挡的下层头发。移除眼睛、眉毛和嘴，补出带原有肤色渐变的脸底。清除标识，保留空白佩饰底座。透明方形画布，无新物件。
2. **闭眼稿**：只将原位置双眼改为自然闭合的深色细睫毛线，保留原头部透视和轻微侧倾；去掉眼白和虹膜残影。眉毛、微笑、下巴、头发、手和设备保持原样。只提取眼部遮罩内的补片。
3. **完整眼白**：只在原有双眼开口内移除虹膜、瞳孔和高光，补出连续的象牙白眼白和原有浅紫眼睑阴影。保持睁眼轮廓、上下眼线、眉毛和遮挡发丝。只使用原虹膜背后的白色补全区。
4. **设备隐藏区**：移除覆盖鼠标和键盘的手与袖口，保持两个设备原来的位置、比例、轮廓、透视和键位。补全手下的墨蓝鼠标上壳和键盘上边缘；保留靠角色的单根长空格。只取设备轮廓内原来被手遮挡的像素。

源板见 `source/*-raw.png`；实际部件、坐标与遮罩见 `../public/assets/parts/manifest.json` 和 `source/part-masks.json`。这些请求是实际执行内容的归档摘要；原画位图和校标原路径另行保存，不把生图提示当作像素验收结果。
